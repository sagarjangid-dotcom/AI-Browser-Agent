# AI Browser Agent

An AI-powered browser automation system built using Python,
Streamlit, Gemini AI and Playwright.

## Features

- AI-based command understanding
- Browser navigation and search
- Multi-step browser workflows
- Website content extraction
- Excel report generation
- Automated web form filling
- User approval before form submission
- Execution logs and form history

## Technologies Used

- Python
- Google Gemini AI
- Streamlit
- Playwright
- Pandas
- OpenPyXL
- BeautifulSoup

## Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:

   cd AI-Browser-Agent

3. Create a virtual environment:

   python -m venv venv

4. Activate it:

   Windows:
   venv\Scripts\activate

5. Install dependencies:

   pip install -r requirements.txt

6. Install Chromium:

   playwright install chromium

7. Create a .env file and add:

   GEMINI_API_KEY=your_api_key

8. Run the application:

   python -m streamlit run app.py

## Security

Never upload your Gemini API key or .env file
to a public GitHub repository.
